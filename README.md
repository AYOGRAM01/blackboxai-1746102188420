# Space Shooting Game

## Project Overview
Space Shooting Game is an exciting web-based game where players control a spaceship and shoot incoming enemies while dodging obstacles. The game has vibrant graphics, sound effects, and a scoring system to enhance the gaming experience.

## Installation
To run the Space Shooting Game locally, follow these steps:

1. **Clone the repository**:
   ```bash
   git clone https://github.com/yourusername/space-shooting-game.git
   ```

2. **Navigate to the project directory**:
   ```bash
   cd space-shooting-game
   ```

3. **Open `index.html` in your web browser**:
   You can do this by double-clicking on the file or using the file menu in your browser to open the HTML file.

## Usage
- **Controls**:
  - Use the **Arrow Left** or **A** key to move the spaceship left.
  - Use the **Arrow Right** or **D** key to move the spaceship right.
  - Press the **Space** bar to shoot bullets.
  - Click on the **Pause** button to pause or resume the game.

- **Objective**: 
  Score points by destroying enemies while trying to stay alive. Collect power-ups that can enhance your shooting capabilities.

## Features
- Smooth animations and responsive controls.
- Various enemy types with increasing difficulty.
- Power-ups that grant temporary advantages.
- An engaging boss battle every few levels.
- Sound effects that enhance the gaming experience.
- Game over screen with the option to refresh the page to restart.

## Dependencies
This project uses the following external libraries:
- **Tailwind CSS**: For styling (included via CDN)
- **Font Awesome**: For icons (included via CDN)

No package.json file or Node.js dependencies were identified in the project setup.

## Project Structure
Here's a brief overview of the project structure:

```
/space-shooting-game
│
├── index.html         # The main HTML file for the game.
├── main.js            # The main JavaScript file that contains game logic.
```

### index.html
- The HTML file sets up the game interface, including the canvas for gameplay, UI for score and lives, and styles for a visually appealing layout.

### main.js
- Contains the game's functionality, including:
  - Game state management (score, lives, paused state).
  - Player controls and movement logic.
  - Enemy and bullet spawning mechanics.
  - Collision detection and power-up handling.
  - Rendering and animation loops for the game.
